# TRIYUTA — Plants & Gifts

A lightweight, responsive information website. No dependencies or build step.

## Preview
Open `index.html` in a browser, or serve the folder:

    python -m http.server 8000

## Deploy to Vercel
1. Extract this ZIP and upload the contents of `triyuta-website` to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: **Other**. Leave Build Command empty. Output Directory: **.** (project root).
4. Deploy. No environment variables are required.

Alternatively, run `npx vercel` from this folder using your own Vercel account.
